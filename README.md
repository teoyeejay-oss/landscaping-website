# Landscaping Website (Concept Project)

A mobile-first homepage and small multi-page website for a fictional landscaping and lawn care company. This is a portfolio project I'm building to practice creating professional websites for small local service businesses.

> **Note:** The company, reviews, licence details and phone number are all sample content. They do not represent a real business.

## Status

Work in progress. Currently building the homepage structure in plain HTML.

## Goals

- Build a clear, trustworthy website that helps visitors understand the services and request a free quote
- Practice semantic HTML, responsive layout and accessible design
- Design for phones first, then larger screens

## Planned pages

## Homepage sections

- [ ] Services
- [ ] Why Choose Us (reviews, licensed and insured)
- [ ] Footer with contact details and a second call to action

Later: Before and After, About the Owner, FAQ, Service Areas.

## Built with

- HTML
- CSS (Flexbox and Grid)
- JavaScript (navigation menu, form validation)

## Design approach

I studied several local landscaping company websites to understand what visitors expect to see, such as clear services, trust signals and an easy way to get in touch. The layout and all written content in this project are my own.
